# MEMORY.md — Durable Facts

**Hermes path:** `$HERMES_HOME/memories/MEMORY.md` (not the profile root).
**Char limit:** 2,200 characters (~800 tokens) per Hermes built-in memory docs.
Prefer short dated bullets; consolidate when near the limit.

Empty log for durable, non-secret facts about the operator's OPSEC posture.
Bourne and the operator append here; nothing else belongs in this file.

## Rules

1. **One fact per entry.** Do not bury multiple claims in a paragraph.
2. **Date every entry** (`YYYY-MM-DD`).
3. **No secrets.** No passwords, seed phrases, API keys, recovery codes, full
   account numbers, or authentication material of any kind.
4. **No third-party dossiers.** Do not store dossiers, dossiers-in-progress, or
   investigative notes about other people. This log is about the operator's own
   defenses only.
5. **Prefer reversible statements.** Prefer "uses a password manager" over
   product brand names that go stale, unless the brand is load-bearing.
6. **Mark uncertainty.** If a fact is provisional, say so.

## Format

```
- YYYY-MM-DD — Fact text. (optional: source or why it matters)
```
