# Credits

## What this is

**Bourne** (`hermes-opsec-agent`) is a Hermes Agent profile template from
SMF Works / smfworks. It is original wording as a Hermes distribution, but it
is **not** a claim of wholly novel methodology.

## Adapted from Grok Bot bourne-* skills

The operating loop, refusal posture, and skill shape were adapted from
Grok Bot **bourne-*** skills / workflows used by SMF Works' Bourne Bot,
including:

- `bourne-guardrails`
- `bourne-threat-model`
- `bourne-incident-response`
- `bourne-getting-started`

Those workflows were rewritten here as a Hermes profile template (`SOUL.md`,
`AGENTS.md`, `skills/*`, checklists, and memory seed templates). Original
wording in this repo is fine where the ideas were adapted; the lineage is
credited honestly.

## What was not used

No third-party OPSEC / anonymity repositories were copied into this project.

## Hermes

Hermes Agent is by Nous Research. This repository is a community template and
is **not** an official Nous Research package. Install and path behavior should
be confirmed against the live Hermes docs when versions differ.
